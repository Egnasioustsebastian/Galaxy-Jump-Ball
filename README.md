# Galaxy Jump Ball 🚀

A fun and challenging 2D arcade game inspired by the classic Flappy Bird gameplay. Control a bouncing ball through a galaxy-themed environment, avoid obstacles, and achieve the highest score possible.

## 🎮 Game Overview

Galaxy Jump Ball is a fast-paced 2D endless runner where players must carefully time their jumps to navigate through obstacles and survive as long as possible. The game features smooth controls, engaging gameplay, and a space-inspired visual style.

## ✨ Features

- Simple and addictive gameplay
- Smooth ball movement and jump mechanics
- Endless obstacle generation
- Score tracking system
- Galaxy-themed environment
- Lightweight and optimized performance
- Built using Unity 2D

## 🛠️ Built With

- **Game Engine:** Unity 2D
- **Programming Language:** C#
- **IDE:** Visual Studio / Visual Studio Code

## 🎯 How to Play

1. Start the game.
2. Click the **Left Mouse Button** or press **Spacebar** to make the ball jump.
3. Avoid hitting obstacles.
4. Survive as long as possible and beat your high score.
